# PISO CHARGE PRO ESP8266

ESP8266 Access Point portal firmware for a coin-operated piso charging station.

The ESP8266 runs offline in AP mode only. It does not connect to the internet. A coin pulse adds charging time, and the user assigns available credit to Port 1, Port 2, or Port 3 from `http://10.20.30.1`.

## Default Access

| Item | Value |
| --- | --- |
| AP SSID | `PISO_CHARGE_PRO` |
| AP password | `12345678` |
| Portal IP | `10.20.30.1` |
| User page | `http://10.20.30.1/` |
| Admin page | `http://10.20.30.1/admin` |
| Admin username | `admin` |
| Admin password | `admin` |

## Wiring Defaults

| Function | NodeMCU Pin | GPIO |
| --- | --- | --- |
| Relay 1 | D1 | GPIO5 |
| Relay 2 | D2 | GPIO4 |
| Relay 3 | D5 | GPIO14 |
| Coin input | D6 | GPIO12 |

Avoid using boot-sensitive pins for relays: D3/GPIO0, D4/GPIO2, and D8/GPIO15.

Relay modules are initialized OFF during boot. Default relay mode is active LOW.

## Manual Firmware Flash

Replace `COMx` with your ESP8266 serial port.

```bash
esptool.py --port COMx --baud 460800 write_flash 0x00000 .pio/build/nodemcuv2/firmware.bin
```

For this Arduino CLI build, using the default NodeMCU `4MB (FS:2MB OTA:~1019KB)` layout:

```bash
esptool.py --port COMx --baud 460800 write_flash 0x00000 build/arduino-cli/firmware.bin 0x200000 build/arduino-cli/data.bin
```

For PlatformIO, either use `pio run --target uploadfs` or flash the LittleFS image generated by PlatformIO for your selected flash layout.

## API

### GET `/api/status`

Returns:

```json
{
  "creditSeconds": 300,
  "coinPulses": 1,
  "ports": [
    {"id": 1, "enabled": true, "active": true, "remaining": 123},
    {"id": 2, "enabled": true, "active": false, "remaining": 0},
    {"id": 3, "enabled": true, "active": false, "remaining": 0}
  ],
  "uptime": 60,
  "freeHeap": 40000
}
```

### POST `/api/start`

Form body:

```text
port=1
```

Transfers available credit seconds to the selected port and turns its relay ON.

### POST `/api/add-credit-to-port`

Form body:

```text
port=1
```

Adds available credit seconds to an active or inactive port.

### Admin APIs

Admin APIs require login cookie from `/admin/api/login`.

- `POST /admin/api/login`
- `GET /admin/api/settings`
- `POST /admin/api/save-settings`
- `POST /admin/api/reset-settings`
- `POST /admin/api/test-relay`

## Safety

AC mains wiring must be isolated, fused, enclosed, strain-relieved, and handled only by someone qualified to work with mains voltage. Prefer switching charger input inside a proper enclosure or switching low-voltage USB charging modules. Never leave exposed outlet wiring or relay terminals accessible to users.
